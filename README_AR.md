# SmartBiz AI — نظام إدارة المبيعات والمخزون

تطبيق ويب عربي من اليمين إلى اليسار باستخدام Python وFlask وMySQL/MariaDB في XAMPP.

## الوظائف الموجودة حاليًا

- تسجيل دخول بكلمة مرور مخزنة بصيغة hash، وحماية CSRF للنماذج.
- لوحة تحكم للمبيعات والمخزون والمصروفات.
- المنتجات: إضافة وتعديل وإيقاف المنتج.
- المبيعات: فواتير نقدية متعددة الأصناف، ربط اختياري بعميل مسجل، خصم المخزون تلقائيًا، وإلغاء الفاتورة مع إعادة الكميات.
- المشتريات: فاتورة متعددة الأصناف، تسجيل المورد، زيادة المخزون تلقائيًا، وحساب متوسط تكلفة الشراء للمنتج.
- العملاء: إضافة وتعديل وبحث، وعرض عدد فواتير العميل وإجمالي مشترياته المرتبطة.
- الموردون: إضافة وتعديل وبحث، وعرض ملخص فواتير الشراء.
- المصروفات وتقارير بفترة زمنية وأفضل المنتجات إيرادًا.
- التحليلات الذكية: اتجاه المبيعات خلال 30 يومًا، مقارنة أسبوعية، أفضل المنتجات، تنبيهات المخزون، وتوقع إحصائي أولي للأسبوع القادم.
- سجل تدقيق للعمليات المهمة وحركات أساسية للمخزون.

**ملاحظة عن التوقعات:** التقدير المعروض إحصائي مبسط يعتمد على المبيعات اليومية المسجلة، وليس ضمانًا للنتائج أو نموذجًا مدربًا على جميع ظروف السوق. تصبح القراءة أفضل عند تسجيل بيانات فعلية ودقيقة لفترة أطول.

## التشغيل على جهازك (Windows + VS Code + XAMPP)

### 1. تشغيل قاعدة البيانات
1. افتح XAMPP وشغّل `Apache` و`MySQL`.
2. قاعدة البيانات `smartbiz_ai` والجداول أنشأتها بالفعل من ملف `init_db.sql`. **لا تستورد الملف مرة أخرى ما دامت الجداول ظاهرة في phpMyAdmin.**

### 2. تثبيت المكتبات
افتح مجلد `smartbiz_ai` في VS Code، ثم `Terminal > New Terminal`. المفروض يظهر مسار الطرفية منتهيًا بـ `SmartBiz_AI_Starter\smartbiz_ai`.

إذا كانت البيئة `.venv` موجودة في المجلد الأب `SmartBiz_AI_Starter` (كما في هيكل المشروع المعتاد)، نفّذ:

```powershell
..\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

إذا لم تكن أنشأت البيئة الافتراضية من قبل، وأنت داخل مجلد `smartbiz_ai`، نفّذ:

```powershell
py -m venv ..\.venv
..\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. إعداد ملف البيئة
انسخ `.env.example` إلى ملف جديد اسمه `.env` داخل مجلد `smartbiz_ai` نفسه، بجوار `app.py`. اترك القيم الافتراضية إذا كان MySQL في XAMPP يعمل بالمستخدم `root` من دون كلمة مرور محليًا. لو أعددت كلمة مرور لـ MySQL، حدّث `DB_PASSWORD` في `.env`.

### 4. إنشاء حساب المدير
من الطرفية نفسها نفّذ:

```powershell
..\.venv\Scripts\python.exe create_admin.py
```

أدخل اسم مستخدم تختاره، واسمك الظاهر، وكلمة مرور لا تقل عن 8 أحرف، ثم أعد كتابة كلمة المرور. **بيانات الدخول هي بالضبط اسم المستخدم وكلمة المرور اللذين أدخلتهما في هذه الخطوة.** لو ظهر أن اسم المستخدم موجود بالفعل، اختر اسمًا آخر.

### 5. تشغيل التطبيق

```powershell
..\.venv\Scripts\python.exe app.py
```

افتح `http://127.0.0.1:5000` في المتصفح وسجّل الدخول ببيانات حساب المدير الذي أنشأته.

## ملاحظات مهمة

- هذه النسخة للتجربة المحلية. وجود رابط محلي لا يجعل التطبيق متاحًا على الإنترنت تلقائيًا.
- قبل نشر بيانات شركة حقيقية، يجب إعداد استضافة تدعم Flask وMySQL، وتفعيل HTTPS، وتغيير `SECRET_KEY`، وإيقاف وضع debug، وحماية ملف `.env`، ووضع نسخ احتياطية منتظمة.
- الدفع الحالي نقدي فقط ولا يوجد متجر عام أو بوابة دفع.
- إدارة الموظفين بصلاحيات متقدمة، وتصدير التقارير إلى Excel/PDF، وإلغاء فواتير الشراء، والنشر الإنتاجي الآمن تحتاج مراحل تطوير واختبار إضافية.
